# KING'S KITCHEN restaurant website

This project was built as a React + Vite restaurant landing and menu experience for KING'S KITCHEN.

## Included pages
- Home
- Menu
- About
- Contact

## Notes
- Menu content is driven from `src/data/menuData.js` for easier updates.
- Restaurant contact details are centralized in `src/config/restaurantConfig.js`.
- Images use Unsplash placeholders for fast setup and easy replacement later.
